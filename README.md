Este repositorio centraliza mi trayectoria técnica durante el **Bootcamp de Data Science**, transformando conjuntos de datos crudos en historias accionables. Aquí demuestro mi capacidad para limpiar, consultar y analizar datos bajo estándares de la industria.

## 🛠️ Stack Tecnológico
*   **Lenguajes:** Python (Numpy, Pandas, Matplotlib/Seaborn), SQL.
*   **Herramientas:** Jupyter Notebooks, Git, Entornos Virtuales.
*   **Habilidades:** ETL, Análisis Exploratorio (EDA), Optimización de Queries.

## 📁 Estructura y Proyectos Destacados

### 🐍 1. Análisis Avanzado con Pandas
*Enfoque: Calidad de datos y descubrimiento de insights.*
*   **Manipulación:** Tratamiento de valores nulos, duplicados y normalización de tipos.
*   **EDA:** Visualización de distribuciones y correlaciones para identificar patrones de negocio.
*   **Hito:** Reducción del tiempo de procesamiento mediante técnicas de vectorización.

### 🗄️ 2. Arquitectura de Consultas en SQL
*Enfoque: Extracción eficiente de grandes volúmenes de datos.*
*   **Consultas Complejas:** Uso de `JOINs` múltiples para conectar tablas relacionales.
*   **Agregaciones:** Segmentación de usuarios y métricas de desempeño mediante `GROUP BY` y funciones de ventana.
*   **Optimización:** Estructuración de código limpio y legible para mantenimiento.
